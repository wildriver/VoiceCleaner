VoiceCleaner: 動画・音声ファイルのノイズを NVIDIA RE-USE で除去する macOS アプリ（Apple Silicon、macOS 15 以降）。

v0.1.1 の変更点:

- サンプルレート（8〜48 kHz はそのまま、それ以外は 48 kHz）とチャンネル数を保持（モノラル・ステレオ・5.1ch などを各チャンネル別々に処理）
- WAV・AIFF・CAF・FLAC・ALAC は同じ形式・同じビット深度で可逆のまま書き出し、それ以外の音声は AAC
- 映像に加えて、2本目以降の音声トラック（iPhone の空間オーディオなど）も再エンコードせずにコピー
- HE-AAC の音声や 5.1ch の AAC を書き出せなかった問題を修正
- モノラル音声で「一時ファイルを読み込めませんでした」となる問題を修正

初回起動時にモデル（約54 MB）をダウンロードします。
